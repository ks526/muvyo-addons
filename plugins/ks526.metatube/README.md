# MetaTube 刮削

把自建 [MetaTube](https://github.com/metatube-community) 服务接入 Vyo 媒体库，作为第三方刮削来源。

- 按番号或关键词搜索候选
- 补全标题、番号、简介、出演、导演、片商、系列、类别、发行日期、时长、评分
- 海报与背景图通过 MetaTube 自带的图片代理取回（`/v1/images/primary|backdrop/…`）
- 可选「中文字幕角标」：封面左上角叠加角标，由 MetaTube 服务端绘制
- 可选「自动翻译」：标题 / 简介翻成中文，支持 Google 免费版、百度、Google、DeepL、OpenAI 引擎

## 使用

1. 安装并启用后，在插件设置里填写 **MetaTube 服务地址**（例如 `http://192.168.1.10:8080`）。内网地址需要在安装确认时勾选「允许访问这个内网服务」。
2. MetaTube 设置了 `TOKEN` 时，在「后端密钥」里填写；没有设置就留空。
3. 打开 Vyo 媒体库的扫描设置，把「资料来源」改为本插件；也可以在条目上手动「重新识别」时选择它搜索。
4. 建议把媒体库类型设为**电影**（MetaTube 只收录单体影片，剧集搜索会返回空）。

## 说明

- MetaTube 会把搜索请求分发到它配置的多个数据源，全部源一遍约 10 秒；可以在插件设置的「限定数据源」里填一个常用源（如 `JavBus`）明显加快。
- 资料来自 MetaTube 对接的站点，个别站点被墙、被限流或解析失败时该来源会跳过；可在 MetaTube 侧调整数据源或网络（代理）。
- 中文字幕角标与翻译都由 MetaTube 服务端完成，本地不需要额外配置；翻译失败时保留原文，不会中断刮削。
- 图片、角标和翻译都走你填写的服务地址。
